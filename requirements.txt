flask → your web framework
gunicorn → required by Render to run app
psycopg2-binary → PostgreSQL connection
⚠️ If you used these in your code, ALSO add them:
If you used sessions/login:
flask-login
If you used forms:
flask-wtf
If you used CORS:
flask-cors
